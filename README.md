# Supplementary Material

## From Semantic Search to a Dedicated Wittgenstein Chatbot: Generative AI as Controlled Research Infrastructure

**Authors:** Filippo Mosca and Alois Pichler

This repository contains the complete experimental material accompanying the article *From Semantic Search to a Dedicated Wittgenstein Chatbot: Generative AI as Controlled Research Infrastructure*.

The material documents a comparative experiment in which five prompts concerning intelligence and artificial intelligence in Wittgenstein were submitted to widely used general-purpose conversational AI systems and to the WAB Wittgenstein Chatbot. All interactions were conducted on 22 July 2026.

The files contain the user prompts, the corresponding responses generated by the general-purpose systems, the responses generated by the WAB Wittgenstein Chatbot, and the primary sources retrieved and displayed by the WAB system.

## Contents

- `Prompt_A_Gemini.md` — Prompt A: Google Gemini (Gemini 3.5 Flash-Lite) and WAB Wittgenstein Chatbot
- `Prompt_B_Claude.md` — Prompt B: Anthropic Claude (Claude Sonnet 5) and WAB Wittgenstein Chatbot
- `Prompt_C_ChatGPT.md` — Prompt C: OpenAI ChatGPT (GPT-5.5) and WAB Wittgenstein Chatbot
- `Prompt_D_Copilot.md` — Prompt D: Microsoft Copilot and WAB Wittgenstein Chatbot
- `Prompt_E_Perplexity.md` — Prompt E: Perplexity (GPT-5 Mini) and WAB Wittgenstein Chatbot

Each file records the system/model information and date of interaction alongside the relevant outputs. For the WAB Wittgenstein Chatbot, the files also report the response-generation model, query-processing model, embedding model, search service, and the primary sources retrieved and displayed.
